Query before mutation: guardrail patterns for agents that touch production infrastructure
Giving an AI agent permission to change production infrastructure removes the human pause that made plan-and-apply safe. In this talk, Jeffrey Aven shows how to put that judgement back into the system itself.

He introduces query before mutation: requiring an agent to establish the live state of an environment before it can write. From there, he develops a practical set of guardrails: idempotent assertions instead of imperative commands, machine-checkable policy gates, tightly scoped credentials and mutation surfaces, and recovery paths for blocked or failed changes.

Drawing on real examples of agents operating against cloud environments, Jeffrey will show where each pattern helps, where it does not, and demonstrate a mutation being blocked and safely recovered.

You’ll leave with an ordered checklist of controls that deliver the most protection for the least implementation effort.
