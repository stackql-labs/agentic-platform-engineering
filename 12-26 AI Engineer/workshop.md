Hands-on workshop

Building Agents That Safely Operate Real Cloud Infrastructure
December 9th 2026 · 1:30 pm–5:00 pm Sydney time

With Jeffrey Aven

AI agents can inspect and change cloud infrastructure—but how do you let them act without giving up control?

In this hands-on workshop, you’ll first build a read-only inventory and audit agent that queries live resources in an isolated cloud environment and reports what is deployed. You’ll then choose a specialisation—FinOps, site reliability engineering, cloud security posture management, or entitlements and access review—and extend the agent to identify issues and recommend a response.

Finally, you’ll move safely from observation to action: the agent proposes a change, a human approves it, and the agent executes and verifies the result.

You’ll leave with a working cloud-operations agent and access to a public MIT-licensed repository containing every workshop track. No personal cloud or model account is required; isolated environments, credentials and model access are supplied.
